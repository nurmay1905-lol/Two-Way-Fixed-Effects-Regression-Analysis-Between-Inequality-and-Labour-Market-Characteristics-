In this Branch you will find the data I have used to undertake this research project. 

gini.csv is the main dataset I have used for gathering data about the gini coefficient.

tu.xlsx is the main dataset I have used for gathering data about Work Council Status (0-2), Adjusted Collective Bargaining Coverage (0-100), and Trade Union Density (0-100).

To ensure I can actually use the data, I have made a series of efforts to clean each dataset up by filtering out irrelevant variables, interpolating NA values, and merging the two datasets together - more of this in the code section.
