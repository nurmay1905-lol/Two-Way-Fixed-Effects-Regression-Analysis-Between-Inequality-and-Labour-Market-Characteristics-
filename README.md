# This Branch Provides the tables comparing model performance 

[table1_twfe.csv](table1_twfe.csv) Demonstrates that the best predictor of Gini within the variables chosen, controlling for year and country, is collective bargaining coverage. This method employs a two-way fixed effects analysis and multiple regression. 

[table2_institutional.csv](table2_institutional.csv) Demonstrates that when adjusted for cross country comparison, the variables associated most strongly with lower Gini is status of Work Councils and Mean union density. This method employs a Mundlak Correlated Random Effects Model to adjust for both cross country and within country comparison, as well as pooled OLS. 

[table3_robustness.csv](table3_robustness.csv) Demonstrates the robustness of my models when adjusted for interpolation and time lag.
